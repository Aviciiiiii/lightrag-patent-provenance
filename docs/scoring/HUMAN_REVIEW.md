# Human review record

In the two reruns, 15 judgments had an uncertain rule or a rule value different from the original run (7 on 11-05, 8 on 11-15). They were reviewed first by Claude Code and then, item by item, by the author on **2026-11-15**. The review was done in Chinese; the author's original note is quoted below and in `human_review_<run>.json` (`note_zh`), next to an English translation by Claude Code (`note_en`). Generated by `tools/build_human_review.py` from the JSON files.

**Agreement**: the author's conclusion equals the Claude Code judgment and the rule value in 15 of 15 items.

Paths are relative to the repository root, with `E1` = `experiments/01_baseline_index_qa/results_rerun_<run>/results`, `E2` = `experiments/02_provenance_ablation_and_chunk_control/results_rerun_<run>/results`, `E3` = `experiments/03_chunk_boundary_full_pipeline/results_rerun_<run>/results`. `edges[n]` counts from 0.

## Criteria in short

| ID | What is judged | “Yes” when (from the [rubric](../SCORING_RUBRIC.md)) |
|---|---|---|
| S1 | experiment 01: the answer completes the core task | no refusal; names all publication numbers; names the claims of the question's evidence (cross-document: any claim within each patent's own paragraph) |
| S3 | experiment 01: the answer **affirmatively** attributes the target facts to another patent | an affirmative misattribution such as “different patent family” |
| S5 | experiment 02 ablation: the registration evidence is attributed to US7991757B2 | an affirmative statement (e.g. “referencing US7991757B2”) and no sentence denying it |
| S9 | experiment 03: F01's target predicates reach the relation records of the merged graph | frozen criterion: the embedding of existing cases **and** experts is based on the medical ontology, and the ontology is based on UMLS; a relation about the new case only does not count ([`frozen_groups.json`](../../experiments/03_chunk_boundary_full_pipeline/conditions/frozen_groups.json) → F01 `researcher_predicate`) |
| S13 | experiment 03 naive: states a claim dependency that contradicts the original | the answer says “A depends on B” where the original differs, or an arrow chain in a paragraph about dependencies contradicts the original |
